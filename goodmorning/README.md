# 굿모닝 뉴스 수집기

등록한 키워드로 네이버 뉴스에서 최근 24시간 기사를 모아 DB(`news.db`)에 쌓고, 엑셀로 내려받는 웹 프로그램입니다.

## 실행 (Windows)

1. Python 3.10 이상이 설치되어 있어야 합니다.
2. 이 폴더를 PC로 복사한 뒤 `run.bat`을 더블클릭합니다.
   - 처음 한 번은 필요한 라이브러리를 설치하느라 1~2분 걸립니다.
3. 브라우저에서 http://127.0.0.1:8000 이 자동으로 열립니다.

네이버 API 키는 `.env` 파일에 들어 있습니다. NAVER API HUB(네이버 클라우드 플랫폼 콘솔)의 Application 인증 정보(Client ID / Client Secret)를 넣으면 되고, 키를 바꾸면 이 파일만 고치면 됩니다.

## 노션 연동 (선택)

수집한 기사를 노션 데이터베이스에도 쌓을 수 있습니다. 설정하지 않으면 지금처럼 DB와 엑셀만 씁니다.

1. https://www.notion.so/profile/integrations 에서 **새 통합**을 만들고(유형: 내부), **내부 통합 시크릿**(`ntn_…`)을 복사합니다.
2. 노션에서 기사를 쌓을 **데이터베이스**(표)를 하나 만듭니다. 빈 표면 충분합니다.
3. 그 데이터베이스 오른쪽 위 **⋯ > 연결(Connections)** 에서 1번에서 만든 통합을 추가합니다.
4. `.env`에 두 줄을 넣고 프로그램을 다시 실행합니다.
   ```
   NOTION_TOKEN=ntn_복사한_시크릿
   NOTION_DATABASE_ID=데이터베이스_링크_또는_ID
   ```
   데이터베이스 링크(⋯ > 링크 복사)를 그대로 붙여넣어도 됩니다.

이후 동작:
- 검색할 때마다 새 기사가 노션에 한 줄씩 추가됩니다. 열(날짜·언론사·지면·영상·URL·키워드·요약)이 없으면 처음에 자동으로 만들어 줍니다. 같은 이름의 열이 이미 다른 종류로 있으면 오류가 나니 이름을 바꾸거나 지워 주세요.
- 화면의 **노션으로 보내기** 버튼은 보고 있는 기간에서 노션에 아직 없는 기사(이전에 실패한 것 포함)를 보냅니다. 연동 전 기사도 이 버튼으로 옮길 수 있습니다.
- 표에서 언론사명·지면·영상을 고치면 노션에도 반영되고, 기사를 삭제하면 노션에서는 휴지통으로 옮겨집니다.

## 화면에서 할 수 있는 일

- **첫 화면을 열면** 켜져 있는 키워드로 최근 24시간 기사를 자동 검색해 목록에 보여주고 DB에 저장합니다.
  (10분 안에 다시 열면 검색을 건너뛰고 저장된 목록만 보여줍니다. 바로 다시 찾으려면 "지금 다시 검색")
- **검색 기간**: "지금 다시 검색" 옆에서 최근 24시간(기본)·48시간·7일·날짜 지정을 고를 수 있습니다. 검색이 끝나면 아래 기사 목록도 같은 기간으로 맞춰집니다.
  - 네이버 API는 키워드당 최신 1,100건까지만 주므로, 아주 긴 기간은 앞쪽 기사가 빠질 수 있습니다(화면에 안내가 뜹니다).
- **키워드**: 추가, 수정(✎), 잠시 빼기(⏸), 삭제(✕). `"따옴표"`로 감싸면 정확히 일치하는 기사 위주로 검색합니다.
- **엑셀 다운로드**: 지금 보고 있는 기간의 기사를 기존 스크립트와 같은 형식(연번·날짜·언론사명·구분·제목·URL)으로 내려받습니다.
  - 지면 기사는 지면 행(다음 날짜, URL "-")이 추가되고, 방송사 영상 기사는 방송 행이 추가됩니다.
- **수정**: 언론사명, 지면, 영상 표시가 틀렸으면 표에서 클릭해 고칠 수 있습니다. 고친 값은 DB에 저장됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 웹 서버 (FastAPI) |
| `collector.py` | NAVER API HUB 뉴스 검색 API 호출 + 기사 페이지에서 언론사명·지면·영상 보강 |
| `db.py` | SQLite 저장 (`news.db`) |
| `exporter.py` | 엑셀 만들기 |
| `notion.py` | 노션 데이터베이스로 기사 보내기 (선택) |
| `static/index.html` | 화면 |

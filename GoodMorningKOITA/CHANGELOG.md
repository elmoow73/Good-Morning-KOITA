# 변경 기록

버전은 `메이저.마이너.패치` 세 자리로 매깁니다.
- 메이저 (1.x.x): 기존과 호환되지 않게 바뀔 때 (예: API 이름 변경, 파라미터 삭제)
- 마이너 (x.1.x): 호환을 유지하며 기능을 추가할 때 (예: 새 기능, 선택적 파라미터)
- 패치 (x.x.1): 호환을 유지하며 버그를 고칠 때 (예: 계산 오류, 보안 패치)

완료 확인 전 시험판은 `1.1.0-rc.1`처럼 뒤에 `-rc.번호`를 붙입니다.

## v1.2.0-rc.4 (2026-10-26, 시험판)
- 지면 확인을 브라우저(Playwright)로 변경: rc.3은 검색 화면 HTML만 받아서 자바스크립트로 그려지는 기사 목록과 지면 표시를 읽지 못했음. 이제 PC의 크롬(없으면 엣지)을 화면 없이 열어 검색 결과를 내려 가며 "A29면 1단" 표시를 읽음. .env에 BROWSER_SHOW=1을 넣으면 브라우저 창이 보임

## v1.2.0-rc.3 (2026-10-26, 시험판)
- 지면 판별을 네이버 뉴스 검색 결과 화면 방식으로 변경: 같은 키워드의 검색 결과 화면에서 기사마다 붙는 "A29면 1단" 표시를 읽어 기사 링크로 맞춤 (예전 크롤러와 같은 출처, 언론사와 상관없이 같은 형식). rc.2의 언론사 원문 페이지 방식은 뺌
- 기사 DB 중복 기준은 엑셀과 같은 URL 기준만 사용 (rc.1의 제목 비교는 뺌)

## v1.2.0-rc.2 (2026-10-26, 시험판)
- 지면 판별 개선: 네이버 기사 페이지에서 못 찾으면 언론사 원문 페이지의 지면 표시("지면 : 2026-10-21 2면", "지면A29", "A12면 1단" 등)를 읽음. 전자신문·한국경제 실제 기사로 확인

## v1.2.0-rc.1 (2026-10-26, 시험판)
- 기사 DB를 저장할 때마다(그리고 프로그램을 켤 때) 기사 날짜 최신순으로 다시 정렬하고 연번을 1부터 다시 매김. 예전에 들어간 중복도 이때 정리

## v1.1.0 (2026-10-22)
- 프로그램명을 GoodMorningKOITA로 변경 (화면, 로그인, 폴더 이름), 화면 제목 옆에 버전 표시
- 기본 키워드를 "한국산업기술진흥협회", "산업기술진흥협회", "산기협", "장영실상", "엔지니어상" 5개로 변경, OR 검색임을 화면에 표시. 예전 기본 키워드 2개는 처음 실행할 때 새 5개로 바뀌고, 직접 추가한 키워드는 그대로 유지
- 기사 목록에 체크 칸 추가. 엑셀 다운로드는 체크한 기사만
- DB 저장 버튼 추가: 체크한 기사를 기사 DB(SQLite 원본 + CSV·JSON 사본)에 중복 없이 이어 붙임. 위치는 .env의 ARCHIVE_DIR (없으면 database 폴더)
- 기사 목록에 언론사·키워드 선택 목록과 정렬(최신순, 오래된순, 언론사순, 키워드순) 추가

## v1.0.0 (2026-10-20)
첫 공개 버전.
- NAVER API HUB 뉴스 검색으로 키워드(한국산업기술진흥협회, 산기협) 기사 수집
- 기사 페이지에서 언론사명·지면·영상 여부 보강, SQLite(news.db)에 저장
- 웹 화면에서 키워드 관리, 기사 목록 확인, 엑셀 내보내기
- 선택 사항: .env의 APP_PASSWORD로 로그인 보호

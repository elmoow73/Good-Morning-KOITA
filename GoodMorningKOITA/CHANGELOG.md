# 변경 기록

버전은 `메이저.마이너.패치` 세 자리로 매깁니다.
- 메이저 (1.x.x): 기존과 호환되지 않게 바뀔 때 (예: API 이름 변경, 파라미터 삭제)
- 마이너 (x.1.x): 호환을 유지하며 기능을 추가할 때 (예: 새 기능, 선택적 파라미터)
- 패치 (x.x.1): 호환을 유지하며 버그를 고칠 때 (예: 계산 오류, 보안 패치)

완료 확인 전 시험판은 `1.1.0-rc.1`처럼 뒤에 `-rc.번호`를 붙입니다.

## v1.2.0 (2026-10-26)
- 검색·목록 기간을 날짜(0시) 기준으로 변경: 오늘 / 어제부터(기본) / 최근 7일 / 날짜 지정 (내부 기간 값 hours → days)
- 지면 판별: 네이버 뉴스 검색 화면(상세검색, 따옴표 완전일치, 최신순, 같은 기간)을 브라우저(Playwright, 크롬→엣지)로 키워드별 탭에서 동시에 끝까지 내려 "A16면 1단", "1면 TOP" 등 "면" 표시를 읽고 기사 링크(안 맞으면 제목)로 맞춤. 이미 수집된 기사에도 반영
- API(키워드당 최신 1,100건) 밖 기사는 검색 화면에서 더함 (URL로 중복 제외, 게재일시 그날 00:00:00). 목록에 "출처"(API / 검색화면) 칸과 선택 목록 추가
- 목록에서 지면·방송 기사도 [온라인]을 같이 표시, 영상 표시는 "방송"으로 이름 변경
- 기사 DB: 저장할 때마다 게재일시(published_at) 최신순으로 정렬하고 연번을 다시 매김. 중복은 엑셀과 같은 URL 기준
- CSV가 엑셀 등에 열려 잠겨 있으면 다시 시도하고, 안 되면 koita_news_갱신대기.csv에 저장
- 언론사·키워드 선택 목록을 가나다순으로 정렬 (건수 표시)
- 안내에 검색 화면 기사 수, 지면 수, 맞춘 수, 검색 화면에서 더한 기사 수 표시
- requirements에 playwright 추가

## v1.1.0 (2026-10-22)
- 프로그램명을 GoodMorningKOITA로 변경 (화면, 로그인, 폴더 이름), 화면 제목 옆에 버전 표시
- 기본 키워드를 "한국산업기술진흥협회", "산업기술진흥협회", "산기협", "장영실상", "엔지니어상" 5개로 변경, OR 검색임을 화면에 표시. 예전 기본 키워드 2개는 처음 실행할 때 새 5개로 바뀌고, 직접 추가한 키워드는 그대로 유지
- 기사 목록에 체크 칸 추가. 엑셀 다운로드는 체크한 기사만
- DB 저장 버튼 추가: 체크한 기사를 기사 DB(SQLite 원본 + CSV·JSON 사본)에 중복 없이 이어 붙임. 위치는 .env의 ARCHIVE_DIR (없으면 database 폴더)
- 기사 목록에 언론사·키워드 선택 목록과 정렬(최신순, 오래된순, 언론사순, 키워드순) 추가

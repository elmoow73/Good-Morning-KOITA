# 변경 기록

버전은 `메이저.마이너.패치` 세 자리로 매깁니다.
- 메이저 (1.x.x): 기존과 호환되지 않게 바뀔 때 (예: API 이름 변경, 파라미터 삭제)
- 마이너 (x.1.x): 호환을 유지하며 기능을 추가할 때 (예: 새 기능, 선택적 파라미터)
- 패치 (x.x.1): 호환을 유지하며 버그를 고칠 때 (예: 계산 오류, 보안 패치)

완료 확인 전 시험판은 `1.1.0-rc.1`처럼 뒤에 `-rc.번호`를 붙입니다.

## v1.3.0-rc.4 (2026-11-03, 시험판)
- DB 편집기 "붙여넣어 가져오기": 예전 DB를 엑셀에서 머리글 행까지 복사해 붙여넣거나 CSV 파일(UTF-8·한글 엑셀 CSV)을 열면 머리글 이름으로 열을 맞춰 새 행으로 넣음
  - 미리보기에서 추가할 행 / 이미 있음(온라인·방송은 URL, 지면은 같은 언론사·제목) / 형식 오류(어느 칸이 문제인지)를 나눠 보여 줌
  - 게재일시가 없으면 날짜 0시, 키워드·분류가 없으면 빈 값. 날짜는 2025.01.10., 2025-01-10, 20250110, 엑셀 날짜 숫자를 읽음
  - 표에 넣은 뒤 저장을 눌러야 SQLite·CSV·JSON에 들어감

## v1.3.0-rc.3 (2026-11-03, 시험판)

## v1.3.0-rc.2 (2026-11-03, 시험판)

## v1.3.0-rc.1 (2026-11-03, 시험판)
- 기사 목록에 **분류** 열 추가 (키워드 오른쪽): 선택 / 보도자료 / 특별보도 / 인용 / 장영실상 / 엔지니어상 / 협력 / 언급 / 이슈 / 기타. 고르면 바로 기억하고, DB 저장을 누르면 기사 DB 맨 오른쪽 `category`(분류) 열에 들어감
  - 이미 DB에 있는 행도 분류를 골라 다시 DB 저장하면 새 값으로 덮어씀 ("선택"으로 두면 예전 값 유지)
  - 기존 기사 DB는 처음 켤 때 `category` 열이 자동으로 더해짐 (빈 값). 열 추가만 있어 다른 프로그램과 호환 유지
- **DB 편집** 창 (`/editor`, 위쪽 "DB 편집" 버튼): 기사 DB를 엑셀처럼 직접 고치기. 방향키·Enter 칸 이동, 엑셀에서 여러 칸 복사·붙여넣기, 열 머리 눌러 정렬, 찾기·구분 골라 보기, 행 추가·삭제, 고친 칸 노란색, Ctrl+S 저장
  - 저장하면 SQLite 원본을 바꾸고 CSV·JSON도 같은 내용으로 다시 만듦. 날짜·URL 형식, 빈 칸, 중복 행을 검사해 문제 칸을 빨갛게 표시하고 저장하지 않음
  - 편집기를 연 뒤 다른 곳(DB 저장 등)에서 DB가 바뀌었으면 덮어쓰지 않고 다시 불러오라고 안내
- **지면보도 날짜 확인** (편집기 버튼): 지면 기사 폴더(`.env` `NEWSPAPER_DIR`, 하위 폴더 포함)의 파일명 `[매체명]_기사제목_지면_날짜.jpg`를 읽어 DB 지면 행과 매체명·제목으로 짝짓고 날짜·지면을 비교
  - 틀림(날짜·지면이 다름: 파일 값 ↔ DB 값), 파일명 오류(어느 칸을 못 읽었는지), DB에 없음, 중복 파일, 파일 없는 DB 지면 행을 나눠 보여 줌
  - 고칠 항목을 체크해 "표에 반영" → 확인 후 "저장"으로 고침 (DB는 바로 바뀌지 않음)
  - 폰·클라우드 서버에서는 "폴더 직접 고르기"로 내 기기 폴더의 파일명만 보내 비교 (파일은 올리지 않음)
- `cli.py`: 화면 없이 실행 (AI 에이전트·예약 작업용, JSON 출력·종료 코드). `print-check [--folder] [--apply]`, `archive-rows`
- API: `GET/PUT /api/archive/rows`, `POST /api/print-check`, `PATCH /api/articles/{id}`에 `category`

## v1.3.0 (2026-11-02, PR #4 내용 · 아직 확정 전)
- 앱 설치(PWA) 지원: 안드로이드 폰 홈 화면, PC 크롬·엣지 앱 창으로 설치 가능 (`manifest.webmanifest`, `sw.js`, 아이콘). 서비스 워커는 캐시하지 않고 늘 서버 값을 씀
- 클라우드 서버용 설정 추가 (모두 선택, 비우면 예전과 같음): `DATA_DIR`(news.db·database 위치), `HOST`·`PORT`, `OPEN_BROWSER`, `SESSION_SECRET`(재시작해도 로그인 유지)
- `GET /healthz`: 로그인 없이 부르는 상태 확인 JSON (`{"ok": true, "version": "..."}`, 문제 있으면 503)
- `Dockerfile` 추가 (크로미움·한글 글꼴 포함, 데이터는 `/data`)
- `deploy/`: Oracle Cloud 무료 서버 설치·업데이트 스크립트 `setup.sh`(Docker 설치, 방화벽, `.env`, sslip.io 주소 + Caddy HTTPS 자동, 결과 JSON·종료 코드), 구글 드라이브 백업 `backup.sh`(rclone, SQLite 일관 사본, 최신 + 날짜별 30일, cron 등록)
- 폰 화면에서 기사 표가 넘치면 가로 스크롤, 긴 오류 문구 줄바꿈

## v1.2.0 (2026-10-26)

- API(키워드당 최신 1,100건) 밖 기사는 검색 화면에서 더함 (URL로 중복 제외, 게재일시 그날 00:00:00). 목록에 "출처"(API / 검색화면) 칸과 선택 목록 추가
- 목록에서 지면·방송 기사도 [온라인]을 같이 표시, 영상 표시는 "방송"으로 이름 변경
- 기사 DB: 저장할 때마다 게재일시(published_at) 최신순으로 정렬하고 연번을 다시 매김. 중복은 엑셀과 같은 URL 기준
- CSV가 엑셀 등에 열려 잠겨 있으면 다시 시도하고, 안 되면 koita_news_갱신대기.csv에 저장
- 언론사·키워드 선택 목록을 가나다순으로 정렬 (건수 표시)
- 안내에 검색 화면 기사 수, 지면 수, 맞춘 수, 검색 화면에서 더한 기사 수 표시
- requirements에 playwright 추가
